# Clínica Veterinária Patinhas 🐾

Site de marcação de consultas para uma clínica veterinária fictícia: marcar uma consulta, ver a lista de marcações, pesquisar, filtrar e cancelar.

**▶ Abrir o site:** https://danianecrissouza99-creator.github.io/Projeto_Clinica_Erros/

Projeto da UC **Testes e Qualidade de Software** (ISTEC). O site tem defeitos de propósito: o objetivo é encontrá-los, registá-los e corrigi-los.

Feito com HTML, CSS e JavaScript.
